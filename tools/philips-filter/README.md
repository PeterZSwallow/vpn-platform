# Philips Filter

GUI-программа (Python + tkinter): берёт большой XLSX-файл, находит строки, где в любой ячейке
встречается **Philips / Phillips / Филипс / Филлипс** (без учёта регистра, также внутри слов —
«PHILIPS», «Филипса»), и сохраняет только эти строки в `Philips.xlsx`.

## Установка и запуск

```bash
pip install openpyxl
python philips_filter.py
```

1. «Обзор…» → выберите входной `.xlsx`.
2. Файл вывода по умолчанию — `Philips.xlsx` в той же папке (можно изменить).
3. «Найти и сохранить».

## Особенности

- Потоковое чтение/запись (`openpyxl` read_only / write_only) — подходит для файлов на сотни тысяч строк.
- Обрабатываются все листы; найденные строки попадают в лист с тем же именем.
- Опция сохранения первой строки (заголовка) каждого листа.
- Сохраняются значения ячеек (формулы — как вычисленные значения), форматирование не копируется.
- Кнопка «Стоп» прерывает обработку.

На Linux может понадобиться `sudo apt install python3-tk`.
