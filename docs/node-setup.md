# Настройка VPN-ноды (VLESS + Reality)

Нода — это VPS с Xray, которым управляет панель 3x-ui. Через API панели дашборд создаёт для каждого устройства отдельного клиента со сроком действия. Нода сама отключает клиента, когда срок истекает.

## Установка одной командой

1. Задайте в `.env` дашборда `NODE_REGISTRATION_TOKEN` (любая длинная случайная строка) и перезапустите его.
2. Купите VPS: Ubuntu 22.04/24.04 или Debian 12, от 1 vCPU / 1 GB RAM, с публичным IPv4.
3. Откройте в дашборде **Серверы → «Установить новую ноду одной командой»** и выполните показанную команду на VPS под root:

```bash
curl -fsSL https://<дашборд>/install.sh | sudo bash -s -- \
  --dashboard https://<дашборд> --token <NODE_REGISTRATION_TOKEN> \
  --country NL --city Amsterdam --name "Netherlands #1"
```

Через 1–2 минуты сервер появится в списке со статусом `online`.

### Что делает скрипт

- ставит зависимости и включает BBR;
- скачивает последнюю 3x-ui и заменяет её ядро Xray на проверенную версию (см. ниже);
- задаёт случайные логин, пароль, порт и секретный путь панели, выпускает для неё самоподписанный TLS-сертификат и получает API-токен;
- генерирует ключи Reality (x25519) и Short ID, создаёт inbound VLESS + Reality + Vision на порту 443;
- регистрирует ноду в дашборде, передавая ключи, токен панели и её сертификат. Дашборд доверяет только этому сертификату;
- сохраняет все значения в `/root/vpn-node.env` (права 600).

### Опции

| Опция | По умолчанию | |
| --- | --- | --- |
| `--country CC` | — | Код страны (обязателен при регистрации) |
| `--city`, `--name` | — | Как сервер выглядит в приложении |
| `--tier free\|premium` | `free` | `premium` — только для подписчиков |
| `--sni DOMAIN` | `www.microsoft.com` | Сайт-маскировка Reality (см. ниже) |
| `--port N` | `443` | Порт VLESS |
| `--panel-port N` | случайный | Порт панели 3x-ui |
| `--host HOST` | авто | Публичный IP или домен ноды |
| `--xray-version TAG` | `v25.12.8` | Версия ядра Xray |
| `--force` | — | Переустановить поверх существующей установки (все клиенты на ноде удаляются; дашборд пересоздаст их при следующем подключении) |

Без `--dashboard` скрипт только печатает значения для ручного добавления сервера.

## Важно

**Версия Xray.** С Xray 26.x, который идёт в комплекте с 3x-ui, клиенты sing-box (в том числе iOS-приложение) не проходят аутентификацию Reality. Это проверено на sing-box 1.12.12 и 1.13.0. С Xray 25.12.8 всё работает, поэтому скрипт ставит её. **Не обновляйте ядро Xray из интерфейса 3x-ui**, пока совместимость не проверена.

**Сайт-маскировка (`--sni`).** Нужен сайт с TLS 1.3 и HTTP/2, доступный из страны пользователей и не заблокированный в ней. Лучше выбрать сайт, физически близкий к VPS (тот же хостинг или CDN). Скрипт предупредит, если сайт не отвечает по TLS 1.3.

**Порт панели.** Дашборд обращается к панели по HTTPS. Если на VPS включён файрвол, порт панели должен быть открыт для IP дашборда (скрипт сам открывает порты в `ufw`, если он включён). Порт подписок 3x-ui (2096) приложению не нужен, его можно закрыть.

## Ручная настройка (Marzban или своя 3x-ui)

**Серверы → Добавить сервер**: адрес и порт VLESS, Public key, Short ID, SNI, тип панели, URL панели, логин и пароль или API-токен (3x-ui 3.x: `x-ui setting -getApiToken`), ID inbound. Для самоподписанного сертификата панели вставьте его PEM в поле «Сертификат панели».

Для Marzban: URL — адрес панели без `/dashboard`; Inbound — **tag** VLESS Reality inbound (например `VLESS TCP REALITY`).
